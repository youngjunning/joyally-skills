# Monthly progress report

Write for a reader who needs the month's main progress, business value, and remaining gap in one pass. Reconcile the weekly updates before drafting: merge repeated mentions of the same work, use the latest supported state, and retain the difference between a completed artifact, a live workflow, and measured business impact. A target or planned industry list is not current coverage; name only the industries with concrete recorded scenarios and state what stage each has reached.

Lead with a useful summary, then follow the categories the author specified. Give the author's core category the most attention. The summary should name the central work, representative outcomes across the categories, and material unfinished verification; it should orient the reader without repeating every item. Use descriptive item titles at the smallest useful scope. Split unrelated scenarios that have different owners, value, results, or evidence rather than hiding them under one broad heading. Objective and key-result IDs belong in the reading flow only when the author asks for them.

For a business-facing item, separate **business value** from **business result** when that distinction helps the reader. Value explains the friction removed or decision supported; result states what actually shipped, ran, or was measured. Keep expected savings, user-reported volume, platform-wide totals, prototypes, and generated skills distinct from verified impact. Put a material uncertainty next to the claim it limits, in plain prose. Supporting provenance can remain in the source record; avoid a second layer of repeated caveat cards, progress counters, and source-date lines in the reader's document.

Choose a few figures that let the reader inspect a key result or mechanism. Place each beside the relevant item, and keep the explanatory sentence only if the image alone leaves a real question unanswered. Preserve accessible alt text and a usable source link when the destination supports them. An image caption should add context, not restate the adjacent paragraph or expose editorial maintenance notes.

Treat a copied report as a second reading surface. Check the pasted title, category labels, heading levels, paragraph breaks, figures, and links in the destination editor. Website navigation links are not document tags; use the destination's native tags when available, or copy-friendly labels that remain separated and readable if formatting is stripped. The destination product's UI and clipboard code own the implementation; this skill specifies the editorial result and acceptance check.
