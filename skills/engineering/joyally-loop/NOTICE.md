# 来源说明

本技能改编自 Theo Browne 的 [t3dotgg/tstack `sol-loop`](https://github.com/t3dotgg/tstack/tree/11e37a74d0a6868c121cd0910ab2b3bd9873b92a/skills/sol-loop)，上游采用 MIT License。

Joyally 版本将名称改为 `joyally-loop`，把 GPT Sol 与 T3 Code 专用调用方式泛化为 Codex 可自动选择的独立 reviewer 闭环，同时保留有限轮次、最小修复、finding ledger、允许有证据地反驳和明确停止条件。视频转述中常见的 “Soul Loop” 实际对应上游的 `sol-loop`。
