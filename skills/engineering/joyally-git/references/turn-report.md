# Git 收尾结果契约

`joyally-git` 独立核验并输出仓库、Git 和交付事实；调用方将核验结果放入独立的收尾区。

## 每仓库输出

每个实际工作的 Git 仓库单独一行：

```markdown
> **项目名** `当前分支`：工作区有本任务改动；commit 未创建；push 未执行；测试通过；未部署
```

1. 先写仓库显示名和当前分支。detached HEAD 显示短 SHA 和“未关联分支”，不冒充某个起始或上游分支。
2. 分别写本任务的工作区、commit 和 push 状态。commit 成功后显示本任务短 SHA；push 成功只在回读目标 ref 包含该 commit 后报告。
3. 再按实际需要写测试、构建、制品、部署、分发或真实业务验收。这些门槛互不代替，没有证据的后续门槛写“未执行”或“未验证”。
4. 无关已有改动只说明它们影响了哪个交付决定，不计入本任务结果。多仓库分别输出，不把单仓库成功推广为全部完成。

没有 Git 仓库或本轮是纯只读任务时不制造仓库行。本契约只负责领域事实与展示，不负责最终报告标题、其他 Skills 状态或蒸馏结果。
