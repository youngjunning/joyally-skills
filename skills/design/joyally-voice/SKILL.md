# Joyally Voice

把声音身份、语言内容和表演控制分开处理。先确认使用权和真实交付目标，再选择录音、修复、合成或转换链路；短样通过以后才批量生成。

## 边界

- 本 Skill 主导说话与歌唱中的人声身份、发音、情绪、音色、清晰度、转写和对齐。
- `joyally-music` 主导作曲、歌词与旋律结合、编曲、整曲生成、混音和母带。歌曲任务可以联合使用：Voice 对人声负责，Music 对歌曲整体负责。
- 视频工作流负责画面、时间线和最终封装；本 Skill 交付可引用、可复现、经过验收的人声音轨及时间戳。

## 工作流

### 1. 定义 Voice brief

确认主任务：真实录音、TTS、声音设计、零样本克隆、训练后克隆、说话声转换、歌声音色转换、人声分离/修复、转写/对齐或质量评审。记录语言与口音、说话或歌唱、目标时长、是否实时、目标设备、允许的本地/云端路径和交付格式。

区分三个目标：

1. **内容**：说什么，读音和时间是否正确。
2. **表演**：语速、停顿、情绪、音高与力度如何变化。
3. **身份**：是否需要保持或设计特定音色。

### 2. 建立声音授权

克隆或转换可识别音色前，确认声音属于本人、已得到权利人明确许可，或目标音色不对应真实可识别个人。记录允许的用途、渠道、期限和是否允许训练、再授权及公开发布。没有授权时改用预置音色、文字描述生成的虚构音色或重新录制。

合成音频不得用于冒充、欺诈、绕过声纹验证或制造未经同意的代言。对外成品按平台和场景保留必要的 AI 生成披露；参考录音、模型、输出和授权记录分别控制访问。

### 3. 检查输入

保留原始录音，处理副本。先运行：

先从当前已加载的 `SKILL.md` 定位本 Skill 根目录，再运行；不要假设用户项目也有同名 `scripts/`：

```bash
python3 <joyally-voice-skill-dir>/scripts/audio_audit.py <audio-file> [more-files...]
```

克隆参考优先使用单人、近讲、无混响、无背景音乐、无削波的干声；先做 10–30 秒短样，长训练集再按说话人、语言和录音条件分层。分离得到的人声可以做试验，但分离伪影会进入模型，不把它当成天然干净的训练数据。

### 4. 选择最小链路

读取[工具矩阵](references/tool-matrix.md)。普通配音优先预置音色；只有身份一致性确实重要时才克隆。零样本 TTS 适合快速短样，训练/微调适合长期栏目音色，Voice Conversion 适合保留原表演并更换音色，Singing Voice Conversion 只处理已有歌唱表演，不替代作曲或歌声合成。

沿用项目已有环境；模型、代码、权重和训练数据分别核对许可证。Apple Silicon 优先 MLX 或明确支持 MPS 的路径；CUDA-only 项目先做兼容性核对，不为试一个模型污染项目主环境。

### 5. 先做 A/B 短样

使用同一段包含数字、专名、停顿和情绪变化的文本，或同一段无伴奏歌声，至少比较两个候选。固定模型版本、seed、采样参数、参考音频和文本规范化规则。克隆样本同时保留一个非克隆预置音色基线，避免只凭“像不像”忽略可懂度与自然度。

### 6. 验收人声

逐项检查：

- 内容：漏字、错字、数字、专名、多音字、跨语言发音和字幕时间。
- 表演：语速、停顿、重音、情绪、音高、呼吸和长段一致性。
- 身份：目标音色相似度、跨句稳定性，以及是否意外靠近未授权人物。
- 音质：削波、底噪、混响、金属感、爆音、齿音、断裂、分离伪影和响度。
- 真实结果：目标播放器、耳机与扬声器试听；自动 ASR、说话人相似度和响度指标只作为辅助证据。

重要人声由未参与生成的人完成盲听。短样通过后按自然段或乐句生成，统一响度并在拼接点复听；不要一次生成整篇后只检查开头。

### 7. 交付可追溯资产

交付原始输入的受控位置、处理后 WAV、发布格式、文本/歌词、句词时间戳，以及模型与权重版本、关键参数、seed、参考音频身份和授权范围。按[人声交付清单](references/delivery-manifest.md)在项目内保存最小 manifest；只引用受控授权记录，不把私密录音或授权原文复制进普通仓库。明确区分本地试听、技术验证、可发布成品和已发布结果。

长期栏目使用克隆音色时，还必须冻结一个带版本的 **voice profile**：优先保存模型可复用的 voice prompt；模型不能序列化 prompt 时，保存同一份母版参考音频与逐字转写的受控引用和哈希。profile 同时固定模型权重版本、运行时、语言、文本规范化、采样参数、seed（模型支持时）和后处理链。后续生成只加载该 profile，不临时更换参考、重算参数或覆盖旧版本；身份输入发生变化时创建新版本并通过固定回归短样后再采用。

声音克隆的详细数据准备与验收读取[克隆协议](references/cloning.md)；旁白、角色台词、有声书和视频配音读取[配音协议](references/dubbing.md)。
