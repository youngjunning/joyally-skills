# Picture-book illustration provider

For a complete picture book, use the installed `joyally-writting` Book mode as the overall production owner. It owns story, page count, exact copy, edition contract, package validation, and delivery. `joyally-design` owns visual direction, page composition, typography, template geometry, and design acceptance. This skill supplies pixels from approved page briefs and owns illustration generation or editing, identity continuity, metadata, and technical image QA.

1. Read the supplied scene, action, camera, visible evidence, identity/style references with roles, text surface, protected objects and canvas. Treat visual direction, composition, typography, and template geometry approved by `joyally-design` as locked input; leave story, copy, and edition decisions with the writing workflow.
2. Apply generation and prompt-compliance guidance; use `image-edit.md` for existing artwork and identity-preserving edits.
3. Generate distinct scenes while preserving recurring characters and props. Leave the requested space for integrated lettering; the writing workflow adds exact lettering when necessary.
4. Extend backgrounds without stretching subjects. Respect supplied safety and binding regions, and visually inspect important content rather than trusting prompt adherence.
5. Return artwork, native pixel dimensions, request metadata, identity findings, and technical image findings. Preserve source illustrations as PNG or high-quality JPEG. API success is neither design acceptance nor book acceptance.

Standalone image-only repairs remain here when story and edition decisions are already supplied.
