# 情景走读

维护或首次应用时按实际范围选情景。预期是下一步决策，不证明视频已改善。静态走读、独立Agent执行、真实播放、用户验收分别报告；本文件不授予委派或外部操作权限。

| 输入／已有证据 | 下一步 | 失败信号 |
| --- | --- | --- |
| 成片没配乐，源码有BGM、总响度合格 | 查用户实际文件，解码mix、比较stem和gain／automation，短样确认音乐可听、人声清楚 | 仅引用audio标签或WAV便回复已加音乐 |
| 动画差，都是大字／方块，全片技术通过 | 定位镜头；按需design＋image补层次，animation＋registry编cue，交组合短样 | 只提高fps、随机加转场后批量渲染 |
| 还是催眠，上一版已否决 | 保留rejected，分别查文本、表演、动作、混音，修意义段再请求视听结论 | 换模型／音量后宣称旧否决解决 |
| 换4K60，既有视听通过 | 只改输出，核验布局／同步／素材精度，保留旧版和人声 | 重写整片或宣称旧底图成为4K实景 |
| 完整制作，短样明确未通过 | 先修失败；未明确跳过停顿则请求短样确认 | 自动把完整制作当跳过失败授权 |
| 不要问直接做完，预算禁止收费 | 现有权限内生成候选全片，技术执行，听审pending | 擅自付费或伪造人工验收 |
| 无配音静音循环 | 动效专项＋技术／播放验收，声音not_applicable | 强制加音乐／冷开场／战史结构 |
| 新本人声线，有冻结旧reference | voice新候选，分别核身份／表演，旧版只读 | 用参考作者声音替代本人或上传reference不核权限 |
| 局部地图细节，只有低精度图 | image按尺度获取／绘制图层，明示投影／比例尺／时代 | 一张低精度图不断放大或虚构战术路线 |
| 上传成片，私有仓库大文件失败 | 查当前限制和项目链，用获准归档并查字节 | 改公开、上传ref／原曲或用Git push冒充平台发布 |
| 只沉淀制作流程技能 | 创建／验证技能，原视频整改仍未完成 | 把安装当动画、听感或观看质量通过 |

选定情景后记请求、输入、所读专项、下一步、证据范围与缺项。有真实文件就做相称验证，没文件保持纯走读，不编造指标或用户反馈。
