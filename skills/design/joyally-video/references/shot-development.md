# 镜头与分层交接

需要新镜头、美术、地图或叙事整改时读本文件。在写动画代码之前解决“画面帮助观众理解什么”。

## 叙事镜头

先用悬念、反差或未解问题抓住观众，再给必要背景。幽默来自矛盾与选择，不拿受害者经历做笑料。结构、篇幅与时长以栏目为准；并非所有视频都需要冷开场或三个转折。

关键段落写入小型shot表，已有分镜可直接补列：

| 字段 | 可执行内容 |
| --- | --- |
| 意义／事实 | 解释什么，哪句史料或产品行为支持 |
| 主体与层次 | 背景、中景、前景、人物／物件和标签 |
| 动作 | 主体具体做什么，不只是“元素动一下” |
| 相机 | 推近／拉远、沿路线走或换尺度，焦点是什么 |
| cue | 哪句旁白、词、音效或音乐拍触发可见变化 |
| 进入／退出 | 接上什么，完成时观众知道什么 |
| 停留 | 看图、读字或情绪留白需要多少时间及原因 |
| 素材边界 | 真实影像、历史材料、示意或想象性插画及许可 |

例：“水涨后仍能围城”：地图定位→剖面建立高低关系→水升到低地→依次揭示高地与舟船→回到围城持续的问题。动作解释因果，不把无史料支持的营地或水位画成精确历史复原。

## 美术与动作分开交接

design约束时代气质、层次、留白、色彩与字幕安全区；image落成有质感、可分层的背景／主体／道具。准确文字、坐标和数据留给确定性层，风格参考不混同作品复刻。

动作专项接收已审素材、移动范围、遮挡顺序与cue表。平面插画可用视差、mask、路径绘制、物件动作和相机叙事，无需默认3D。像素素材用真实分层；同物件反复缩放不能伪装不同地图精度。

HyperFrames先查registry中服务该镜头的机制，符合再用；不相符则说明差距，用animation组合少量准确动作。时间线、seek安全与同步规则归hyperframes，不复制到这里。

## 地图叙事分支

地点是核心时，用不同精度的大区域／区域／城市／必要局部图解释位置、距离、路线条件和遗址，保持中心、方向、地点连续，按尺度改变标注密度。

记录来源、时期、投影、近似比例尺与距离类型。现代边界／影像仅供现代定位；研究支持的路线与城市关系线分开。动作揭示已有证据，不增加未经核验的战术箭头、人物容貌或人数。

项目承诺随机选题时沿用其抽样、扩展规则与原始记录，不能为好看偷偷重摇；这不是所有视频的通用随机要求。

## 比较样片

同一意义段、相同旁白和接近的播放条件比较新旧版。先问是否更容易理解、主体明确、动作随叙述完成，再问是否漂亮。运动很多、fps高、效果多不是吸引力证据。

保留否决、最弱镜头与未审区间；短样通过后扩展其他意义段，一个漂亮镜头不等于全片通过。
