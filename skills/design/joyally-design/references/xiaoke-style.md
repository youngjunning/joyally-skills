# 小可风格视觉主题

小可风格是独立的融合主题。它取[香奈儿风](fashion-xiaoxiang.md)的黑白对比、暖金细边和编辑式标题；取 Apple 的[设计原则](https://developer.apple.com/design/human-interface-guidelines/design-principles/)、[布局](https://developer.apple.com/design/human-interface-guidelines/layout)与[材质层级](https://developer.apple.com/design/human-interface-guidelines/materials)中的清晰层级、轻盈材质和精确反馈；取素境的留白、疏密与安静的工作顺序。默认画面保持明亮，以银白、石墨和少量暖金形成识别，不把科技感等同于蓝色或深色大屏。这些是设计方法来源，不暗示 Apple 或 Chanel 授权，也不复制其商标、系统控件或产品页面。

## 空间与内容

| 区域 | 规则 | 验收点 |
| --- | --- | --- |
| Landing 首屏 | 标题、说明与主操作沿共同轴线排列，关键短语保留衬线气质；另一侧只放一幅原创时装视觉示意，旁边只叠一张有实际信息的轻面板 | 遮去图像仍能读出用途与下一步；窄屏按文字、主视觉、数据排序 |
| 工作台 | 任务记录、评测、建议与小界反馈保持稳定顺序；用静区、编号和细线分组，证据与操作放在实色表面 | 不靠时装图片完成高频工作；同一建议的来源、状态和动作清楚 |
| 次级素材 | 山茶花、织纹与金属细边只进入画册、局部边缘或展示区域 | 正文、表单、表格和任务证据背后不铺图案 |
| 导航与状态 | 顶层导航与切换控件可用受控透光材质，正文与内容卡片保持实色；石墨承载主操作，暖金只用于编号、焦点和局部滚边 | 键盘、触控、200% 放大和减少动态效果下仍可完成任务 |

浅色默认使用银白画布 `#F7F7F6`、实色白面、石墨正文与主操作 `#242427`、金属灰边界 `#C7C8CB`。暖金 `#AD8D5B` 仅承担少量编辑式细节；成功、警告和错误各用独立语义色并附文字。深色仅作为可选状态，不能让产品默认变成黑色后台。色值见[语义 token 样本](../assets/xiaoke-style.tokens.json)；平台已有 token 时映射到现有角色。

字体以清晰的中文无衬线正文和控件为基线，展示标题以无衬线建立科技感，在关键词保留少量宋体或衬线；不要以细字重、过宽字距或降低对比度营造精致感。按钮用完整圆角建立触控感；内容卡片保持适度圆角和细边，透光与模糊仅用于顶层导航和控件。动效只提示状态变化，尊重 Reduced Motion。

## 与现有主题的差异

香奈儿风的首屏可以使用多元素编辑式拼贴，小可风格的 Landing 只留一幅主视觉；工作台用银白层次、精确反馈和轻盈悬浮的导航形成科技感。素境用更长的静区和纵向阅读次序，小可风格在静区中保留任务指标、暖金细节和有依据的反馈。主题切换不隐藏评测、建议或小界接收路径。

代表页先核对首屏、一个内容分组和一条操作路径，再检查浅深色、窄屏、长文本、键盘焦点与状态反馈。内站示例的包袋与山茶花图片沿用现有 AI 视觉示意，不作为实拍或品牌授权素材。
