# 自动蒸馏轻量门禁

最终回复前只检查本轮新增内容，不扫描历史会话或既有数字分身。

以下任一情况命中，才加载完整蒸馏协议：

1. 用户明确表达需要长期保留的判断、选择、纠正、想法或价值取舍。
2. 用户明确要求收藏、保存或记住某个外部资源、解释、方法或对话内容。
3. 本轮新写或实质修订了面向读者的文章正文，其中有可以独立复用的观点、概念或方法。
4. 本轮出现了可能持续出现的做事方式、协作习惯或关注主题，且有具体材料支持。
5. 用户指出相邻轮次存在漏记，或明确要求处理指定历史材料。

普通问答、配置命令、代码修改、测试、构建、提交、发布、状态查询和任务完成确认默认不命中；其中若同时包含上述独立内容，仍按内容命中。

未命中时报告“蒸馏：无新增”。命中不等于所有内容都应保存；完整协议仍需判断依据、受众、重复和敏感边界。
