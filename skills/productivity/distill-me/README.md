# Distill Me

把硅基紫升已经在使用的“每轮自动蒸馏”带到你平时使用的 Agent 里。安装后，Codex、千问办公或其他支持 Skills 与长期指令的宿主，会在日常协作收尾时轻量判断本轮是否有值得留下的内容，命中后才整理到本机数字分身。

数字分身包含“个人记录、做事方式、文章、百宝箱、关注主题”5 个栏目。内置工作台用于查看、确认、补充和导出结果；不需要部署、账号、数据库或远程服务。

## 两句话开始使用

在支持 Skills 的 Agent 中依次复制下面两句话。Codex、千问办公或其他能够安装本地 Skill 的宿主都可以执行。

### 1. 安装 Skill，并启用每轮自动蒸馏

```text
请从 https://github.com/youngjunning/joyally-skills/tree/main/skills/productivity/distill-me 把 distill-me Skill 安装到用户级全局目录 ~/.agents/skills/distill-me，只安装这一份。检查千问办公兼容入口 ~/.qwenworkcn/skills：不存在时创建指向 ~/.agents/skills 的软链接，已经是该链接时保留，存在冲突文件或目录时不要覆盖并向我报告。安装时读取其中的 references/host-integration.md，把 distill-me 的每轮自动蒸馏区块写入当前 Agent 确实会在每轮读取的用户级 AGENTS.md 或等价长期指令：修改前先备份，保留其他已有指令，使用安装后的 Skill 绝对路径，按标记区块幂等写入并回读验收。只有 Skill、兼容入口和长期指令都验收通过，才告诉我“自动蒸馏已启用”，并报告三者的位置与回读结果；如果宿主没有等价的每轮指令入口，只报告“Skill 已安装、自动蒸馏未启用”，不要安装 Hook，也不要把自动匹配 Skill 当成每轮自动调用。
```

### 2. 初始化本地工作台

```text
请使用 distill-me 初始化我的本地数字分身：准备内置工作台所需的本地依赖并打开工作台，确认本地数据文件可写；同时回读安装时接入的用户级 AGENTS.md 或等价长期指令，确认其中的 distill-me 区块只出现一次、使用当前 Skill 的绝对路径且没有残留占位符。所有数据只保存在我的本机；不部署，不创建账号、数据库或远程服务。完成后告诉我 Skill 安装位置、长期指令文件及其回读结果、本地数据位置和工作台访问地址；长期指令未通过验收时请明确说明自动蒸馏未启用。
```

初始化完成后，照常使用 Agent 即可。普通命令、代码修改、测试和状态查询不会单独变成个人内容；当你明确表达判断、选择、纠正、方法、值得长期保留的资料，或新写了值得继续发展的文章时，Agent 才会蒸馏本轮增量。工作台会显示自动蒸馏结果，也保留手动补充材料的入口。

## 自动蒸馏如何工作

1. 你照常用 Codex 或其他 Agent 完成工作。
2. 主任务完成后，Agent 只检查本轮新增内容；未命中时直接结束。
3. 命中时，Agent 区分事实、你的明确表达和 Agent 归纳，只保留有依据的增量。
4. 结果写入本机数据文件，工作台会显示它们属于哪些栏目。

自动蒸馏是每轮收尾时的内容处理，不是后台监听、全量历史扫描或云端同步。它只在当前宿主确实读取到已初始化的长期指令时运行；不依赖 Hook 注入提示。

## 常用提示词

### 再次打开工作台

```text
请打开 distill-me 的本地数字分身工作台，沿用现有本地数据，不要重新初始化，也不要部署。
```

### 手动补充一段材料

```text
请使用 distill-me 整理下面的材料。先判断它适合进入“个人记录、做事方式、文章、百宝箱、关注主题”中的哪些栏目，再给我草稿。只写材料能支持的内容，区分事实、我的明确表达和 Agent 归纳，保留来源、不确定性与适用边界；不要发布或同步。

材料：
（把内容粘贴在这里）
```

### 更新 Skill

```text
请把本机已安装的 distill-me 更新到 https://github.com/youngjunning/joyally-skills/tree/main/skills/productivity/distill-me 的最新版本，并统一放到 ~/.agents/skills/distill-me，保留现有本地数据。检查 ~/.qwenworkcn/skills 是否为指向 ~/.agents/skills 的软链接：不存在时创建，已有冲突实体时不覆盖并报告。更新后读取 references/host-integration.md；先备份用户级 AGENTS.md 或等价长期指令，再按标记新增或整体替换 distill-me 区块，随后回读确认区块只出现一次、使用更新后的 Skill 绝对路径且没有残留占位符。再重新打开工作台并告诉我 Skill、兼容入口、长期指令和工作台的验收结果，不要部署。
```

## 本地与隐私

- 工作台不会调用模型或上传材料。
- 自动蒸馏结果保存在 Skill 的本地 `workbench/data/twin.json` 中；主题偏好保留在当前浏览器。
- 导出的 JSON 文件由用户自行保管。
- 初始化授权 Agent 把本轮蒸馏结果写入上述本地数据文件；写入其他位置、发布或对外传播仍需要单独授权。

Agent 无法代为初始化时，参见 [工作台手动启动说明](workbench/README.md)。
