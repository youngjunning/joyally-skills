# Distill Me

把对话、笔记和资料整理成一个只保存在本机的数字分身。它包含“个人记录、做事方式、文章、百宝箱、关注主题”5 个栏目，不需要部署、账号、数据库或服务端。

## 两句话开始使用

在支持 Skills 的 Agent 中依次复制下面两句话。Codex、千问办公或其他能够安装本地 Skill 的宿主都可以执行。

### 1. 安装 Skill

```text
请从 https://github.com/youngjunning/skills/tree/main/skills/productivity/distill-me 安装 distill-me Skill。只安装这个 Skill；安装完成后告诉我安装位置和结果。
```

### 2. 初始化本地数字分身

```text
请使用 distill-me 初始化我的本地数字分身：准备内置工作台所需的本地依赖并打开工作台。所有数据只保存在我的本机；不要部署，不要创建账号、数据库或远程服务。完成后告诉我本地访问地址。
```

初始化完成后，浏览器会打开工作台。把一段聊天、笔记或项目复盘粘贴进去，选择它要进入的栏目，即可先保存为本地片段，或复制请求交给 Agent 继续整理。

## 常用提示词

### 再次打开工作台

```text
请打开 distill-me 的本地数字分身工作台，沿用现有本地数据，不要重新初始化，也不要部署。
```

### 直接整理一段材料

```text
请使用 distill-me 整理下面的材料。先判断它适合进入“个人记录、做事方式、文章、百宝箱、关注主题”中的哪些栏目，再给我草稿。只写材料能支持的内容，区分事实、我的明确表达和 Agent 归纳，保留来源、不确定性与适用边界；不要发布或同步。

材料：
（把内容粘贴在这里）
```

### 更新 Skill

```text
请把本机已安装的 distill-me 更新到 https://github.com/youngjunning/skills/tree/main/skills/productivity/distill-me 的最新版本。保留现有浏览器本地数据；更新后重新打开工作台并告诉我结果，不要部署。
```

## 本地与隐私

- 工作台不会调用模型或上传材料。
- 草稿、栏目选择和主题偏好仅保存在当前浏览器。
- 导出的 JSON 文件由用户自行保管。
- Agent 只有在用户明确指定目标和授权写入后，才可把草稿保存到其他位置。

Agent 无法代为初始化时，参见 [工作台手动启动说明](workbench/README.md)。
