# 蒸馏与工作脉络收尾结果契约

`distill-zisheng` 独立核验并输出“蒸馏”和“工作脉络”两类领域事实。调用方将核验结果放入独立的收尾区。

## 蒸馏

先读取 [轻量门禁](automatic-gate.md)。未命中时输出“蒸馏：无新增”，且不把只读取门禁算作 Skill 已使用。命中时完成自动蒸馏协议，再按实际结果输出：

1. `蒸馏：新增 N 条；更新 M 条`，只计写入、校验与回读都通过的内容。
2. `蒸馏：候选 N 条（原因）`，保存未执行或未获授权时使用。
3. `蒸馏：部分完成（已完成范围；失败对象与下一步）`，或 `蒸馏：失败（对象与下一步）`。
4. `蒸馏：无新增`，只在完整协议允许该结论时使用；未执行、未去重或校验失败不写成零。

## 工作脉络

只处理公司内部、非 GitHub 项目中可回查的业务进展。普通命令、代码、测试、构建、commit 和 push 本身不单独构成工作脉络增量。

1. 公司内部业务进展完成保存、校验和回读时，输出 `工作脉络：新增 N 项` 或 `工作脉络：更新 N 项`。
2. 处于范围内但没有业务增量时，输出 `工作脉络：无增量`。保存未执行或失败时写明对象、原因和下一步。
3. GitHub、公开个人及其他外部项目输出 `工作脉络：跳过（外部项目）`，不为此读取内部目标或建立隐藏条目。

本契约不输出 Skills 列表、Git 状态或最终 `Report` 标题。
