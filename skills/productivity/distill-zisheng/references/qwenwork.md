# 千问办公适配

千问办公将本 Skill 作为普通 `SKILL.md` 技能加载；处理模型、五类内容、证据标准和目标接入约定不变。本页只处理宿主差异，不复制通用蒸馏规则。

## 导入与触发

导入时压缩包保留顶层 `distill-zisheng/` 文件夹，文件夹内包含 `SKILL.md` 及其相对引用的 `references/`、`scripts/`。使用“扩展 → 技能”导入后，可自然语言描述蒸馏任务、在会话中点名 `distill-zisheng`，或从已安装技能列表选择它。安装成功只代表宿主识别了技能；不能据此断言目标已经配置、资料已经读取或内容已经保存。

## 会话输入与目标

启动时确认本轮材料范围、目标和写入意图。用户可通过 `@` 提供仓库、文件夹、接入说明、文章或其他材料；引用只补充上下文，不自动授予写入或跨受众传播权限。目标接入说明应符合[目标接入约定](target-contract.md)：包含根目录/数据位置、支持类型、受众、去重规则和验收方式。

千问办公未暴露可读取的文件、连接器或本机配置时，不能探测路径、猜测默认资料站或要求用户粘贴敏感凭证。改为输出候选，并说明需要哪一份接入文件、授权或可访问资料。对钉钉文档、知识库等连接器，只在用户已完成授权且当前会话实际可调用时读写；连接器返回成功后仍回读目标内容，再报告已保存。

## 自动蒸馏与执行能力

“每轮自动蒸馏”只有宿主或用户明确配置在主任务完成后调用本 Skill 时才执行；千问办公的安装或自动匹配本身不建立每轮回调。触发自动模式时先读[轻量门禁](automatic-gate.md)，命中后再按[自动蒸馏协议](automatic-distillation.md)处理。

脚本、Git、终端、联网与页面验收均取决于当前会话实际提供的能力。可运行时执行相应校验；不可运行时不模拟命令输出，并在结果中明确“未执行”。临时回执可在可写临时空间生成；没有这类空间时，按[处理协议](pipeline.md)的字段在回复中逐项核对，不把回执缺失误报为审计通过。

## 结果表达

始终区分：候选、已写入且回读的内容、只完成草稿的内容、以及因权限或工具缺失未处理的内容。公开、公司和私密受众分别审查；聊天可见、连接器可访问或文档带有 `private` 标记，都不自动构成跨受众或 Git 历史传播授权。
