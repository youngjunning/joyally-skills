# 自动蒸馏轻量门禁

最终回复前只检查本轮新增内容，不读取 `distill-me/SKILL.md`、处理协议、目标配置、历史会话或内容库。

以下任一情况命中，才加载完整蒸馏流程：

1. 用户明确表达需要长期保留的判断、选择、想法、纠正或价值取舍，而不只是要求执行当前任务。
2. 用户明确要求收藏、保存、记住某个外部资源、解释、方法或对话内容。
3. 本轮新写或实质修订了面向读者的文章正文，需要检查其中可独立复用的概念或方法。
4. 本轮提出、决定、推进、验收、暂缓或结束了需要跨轮继续的项目方案。
5. 用户指出相邻轮次存在漏记，或明确要求处理指定历史材料。

普通问答、配置命令、代码修改、测试、构建、提交、发布、状态查询、任务完成确认和只改变工具自身规则的请求默认不命中；其中若同时包含上述独立判断，仍按判断命中。

未命中时直接报告“蒸馏：无新增”，不生成审计回执。命中后读取完整 Skill，并由完整协议决定候选是否实际保存；门禁命中不等于内容合格或获得传播授权。
